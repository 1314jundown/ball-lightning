# 序章配乐槽位

把挑好的曲子放进这个目录，按下面的文件名，页面会自动接上；没有文件就是静音，不会报错。

| 文件名 | 用在哪 | 建议长度 |
|---|---|---|
| shadow.mp3 | 夜窗、蛋糕、影子戏（从开场到球出现之前） | 90–180 秒，可循环 |
| house.mp3 | 白光之后的房屋调查 | 60–90 秒，极安静 |
| dawn.mp3 | 雨停、月出、结尾 | 60–120 秒 |

要求：

- 单曲 ≤ 1.5MB，mp3 即可；
- 无人声、无强节拍；
- 循环点要能接上（首尾电平接近）。

来源与许可见 `docs/音频来源.md`。
